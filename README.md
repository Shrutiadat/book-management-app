## ✨ Features

| Feature         | Description                                    |
| --------------- | ---------------------------------------------- |
| ➕ Add Books    | Add new books with title, author, genre & year |
| ✏️ Edit Books   | Update any book details instantly              |
| 🗑️ Delete Books | Remove books with one click                    |
| 🔍 Search       | Search by title or author in real time         |
| 🎭 Filter       | Filter your collection by genre                |
| 📱 Responsive   | Works beautifully on all screen sizes          |
| 🌙 Dark UI      | Elegant dark glassmorphism design              |

## 🛠️ Tech Stack

- ⚛️ **React.js** — Component-based UI
- ⚡ **Vite** — Lightning-fast dev server & bundler
- 🎨 **CSS3** — Glassmorphism & dark gradient styling
- 🟨 **JavaScript (ES6+)** — App logic

## 📂 Project Structure

```
📦 book-management-system
 └── src/
     ├── 🧩 components/
     │   ├── BookForm.jsx       # Add / Edit book form
     │   ├── BookList.jsx       # Renders full list of books

     ├── App.jsx                # Root component
```

## ⚙️ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/book-management-system.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd book-management-system
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

### 5️⃣ Open in Browser

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

> Output will be in the `/dist` folder, ready to deploy.

---

## 🚀 Deploy on Netlify

### ⚡ Method 1 — Drag & Drop _(Quickest)_

1. Run `npm run build`
2. Go to [netlify.com](https://netlify.com)
3. Drag & drop the `dist/` folder

### 🔗 Method 2 — GitHub Deployment _(Recommended)_

1. Push your project to GitHub
2. Open [Netlify](https://netlify.com) → **Add new site** → **Import from Git**
3. Connect your GitHub repository
4. Set build command: `npm run build`
5. Set publish directory: `dist`
6. Click **Deploy** 🎉
